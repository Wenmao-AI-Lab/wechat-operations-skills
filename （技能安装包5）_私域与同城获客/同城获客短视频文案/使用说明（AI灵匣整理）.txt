## 概述

本 Skill 帮助实体门店商家通过 AI 快速生成高转化率的同城短视频文案，支持日常引流、新品推广和活动促销三大场景。通过建立门店档案（店名、位置、类型、卖点），每次只需一句话即可批量输出3条口语化、合规的短视频文案。

## 核心能力

### 1. 建档式文案生成（对话流程）

首次使用时，引导用户完成4步建档：

1. **选择店铺类型** → 从预设档案中选择（见 `references/profiles.md`）

2. **输入店铺名称** → 如"老李烧烤"

3. **输入所在位置** → 如"杭州萧山"

4. **输入经营年限** → 如"3年老店"

建档完成后，用户可通过以下指令快速生成文案：

- `老样子` → 生成日常引流文案（3条）

- `推新品 [产品名]` → 聚焦新品的推广文案

- `做活动 [活动描述]` → 促销活动紧迫感文案

### 2. 三大生成场景

| 场景 | 触发词 | 适用时机 |

|------|--------|---------|

| 日常引流 | 老样子 | 常规营业日 |

| 新品推广 | 推新品 XX | 上新产品/菜品 |

| 活动促销 | 做活动 XX | 节日/店庆/充值活动 |

### 3. 文案结构规范

所有生成的文案严格遵循**三段式结构**：

- **标签文案**：钩住刷到视频的目标用户

- **广告文案**：展示核心卖点，真实亲切

- **行动文案**：引导用户到店或私信

### 4. 合规要求（重要）

生成文案时必须**严格避免**以下违规词汇：

- 绝对化词汇：最、第一、唯一、极致

- 承诺性词汇：保证、根治、永久、100%

- 虚假对比词：全城最低、全网最便宜

## 工作流程

### 直接生成模式（用户已提供足够信息）

当用户直接描述需求时（如："帮我写一条杭州萧山烧烤店的抖音文案，推荐新品小龙虾"），直接输出3条文案，无需走建档流程。

格式如下：

```

【文案生成 | MM-DD HH:MM】

🎯 场景：[日常引流/新品推广/活动促销]

📹 拍摄建议：[具体拍摄提示]

------------------------

【文案1 - 标签版】

[100字左右口语化文案]

【文案2 - 情感版】

[100字左右口语化文案]

【文案3 - 促销版（如有活动）】

[100字左右口语化文案]

------------------------

🏷️ #推荐话题标签1 #话题标签2 #话题标签3

```

### 对话建档模式（用户信息不足）

当用户只说"写文案"或"帮我做同城推广"时，启动建档流程：

1. 发送店铺类型选择菜单（参考 `references/profiles.md`）

2. 依次询问店名、位置、年限

3. 建档完成后立即生成示例文案

## 使用脚本

`scripts/generate_copy.py` 提供了完整的文案生成引擎实现，可在本地独立运行进行测试：

```bash

python scripts/generate_copy.py

```

支持参数：

- `--profile`：店铺类型ID（如 `restaurant_bbq_basic`）

- `--name`：店铺名称

- `--region`：所在城市/区域

- `--years`：经营年限

- `--scene`：场景（daily/new_product/promotion）

- `--extra`：新品名称或活动描述

- `--api-key`：AI API密钥（可选，不填则使用模拟输出）
