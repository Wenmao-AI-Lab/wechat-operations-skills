【技能标识】wechat21pyq
【功能描述】为品牌/个人IP打造21天朋友圈营销内容计划，解决日更焦虑和内容枯竭问题。当用户需要朋友圈营销内容规划、21天内容计划、IP人设统一、营销节奏规划或运营效率提升时使用。触发词：朋友圈、21天、日更焦虑、内容枯竭、人设割裂、私域运营、朋友圈文案、微信营销、IP打造。
【详细概述】
## 核心任务

基于心理学"认知-情感-行为"三阶段模型，为品牌或个人IP生成**系统化的21天朋友圈营销内容计划**，包含完整执行表。

## 前置信息收集

开始生成前，必须先确认以下信息（缺少则主动询问）：

| 必填项 | 说明 | 缺失时的追问方式 |

|--------|------|-----------------|

| 品牌/IP名称 | 用于个性化文案 | "您的品牌或个人IP叫什么名字？" |

| 人设类型 | 决定文案风格 | 提供四选一：严谨专业 / 亲切温暖 / 幽默风趣 / 务实可靠 |

| 目标用户 | 年龄/职业/核心需求 | "主要面向谁？简单描述一下" |

| 营销目标 | 新客/复购/曝光/转化 | "这21天最想达成什么效果？" |

| 产品/服务 | 主要卖的是什么 | "核心产品或服务是什么？" |

| 历史问题（可选） | 内容没人看？人设不一致？ | "之前发朋友圈有什么困扰吗？" |

## 工作流程

### Step 1：策略生成

根据前置信息确定：

- **三周递进主线**：基于[21天内容框架](references/21-day-content-framework.md)调整各周侧重

- **内容比例分配**：默认 40%信任建立 : 30%兴趣激发 : 30%转化引导

- **时间节奏**：早(干货)/中(生活)/晚(情感+转化)

- **人设风格**：参考[人设类型指南](references/persona-archetypes.md)锁定语言特征

- **历史问题对策**：如有"发布过多被屏蔽"，调整为每日1条高质量；如有"人设割裂"，强化三周一致性

### Step 2：逐日内容创作

为每一天生成一条朋友圈，遵循以下标准：

- **长度**：100-300字

- **结构**：严格遵循[三段式结构](references/post-structure.md)：

  - 开头(10-20字)：拦截注意力（反问/反常观点/场景共鸣）

  - 中间(60-150字)：提供价值（有层次、短段落、混合句式）

  - 结尾(20-50字)：引导行动（互动提问/CTA/态度强化）

- **互动设计**：每篇至少1个互动元素

- **递进感**：21天主题不重复，角度每天变化

- **温度感**：避免机械化模板，体现选定人设的真实人格

### Step 3：输出执行表

使用[执行表模板](assets/execution-template.md)格式输出完整表格，包含：

| 字段 | 要求 |

|------|------|

| 日期 | D1-D21 |

| 时段 | 早/中/晚（匹配时间节奏） |

| 内容类型 | 信任建立/兴趣激发/转化引导 |

| 主题 | 当日主题关键词 |

| 文案 | 完整三段式文案 |

| 互动话术 | 评论引导建议 |

| 替换建议 | 不适合时的替代方向 |

## 可选分支逻辑

- **新人设搭建** → 第一周重点突出个人故事+价值观

- **大促节点临近** → 第三周提高转化内容比例至40%

- **人设割裂问题** → 全程强调一致性检查，每周末做风格审计

- **历史内容过多导致用户屏蔽** → 降至每日1条，首周加入诚恳"重新出发"信号

## 注意事项

1. **转化节奏控制**：前两周不以转化为目的，第三周集中释放

2. **人设统一性**：21天语气、态度、用词风格保持一致

3. **真实感优先**：适度展现脆弱和缺点，比完美人设更可信

4. **灵活调整**：提示用户可根据数据反馈微调后续内容

5. **互动优先**：评论互动是朋友圈营销的核心，互动话术不可省略

6. **递进不可乱**：严格按 信任→兴趣→转化 的顺序，避免前两周硬推
