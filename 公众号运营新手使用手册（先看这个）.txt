┌──────────────────────────────────────────────┐

 需要配置的技能（标 🟡 的）怎么配？
══════════════════════════════════════════════

┌──────────────────────────────────────────────┐
│ ① 公众号凭证（发布/复盘类技能用）            │
│    公众号后台 → 设置与开发 → 基本配置        │
│    拿到 AppID 和 AppSecret                   │
│    对 AI 说：帮我配置公众号凭证，AppID是xxx， │
│    AppSecret是xxx（脚本会存成本地文件）      │
│                                              │
│ ② 红狐 API Key（爆款数据类技能用）           │
│    redfox.hk 注册 → 设置 → API Keys → 复制   │
│    对 AI 说：红狐Key是 ak_xxxx 帮我配上      │
│    （不配也能用免费接口，数据少一些）        │
│                                              │
│ ③ 即梦/OpenAI Key（AI 配图类技能用）         │
│    不需要 AI 配图就完全不用管                │
└──────────────────────────────────────────────┘

⚠️ 安全提醒：AppSecret 别发到群里、别截图外传。

 常见问题
══════════════════════════════════════════════

Q1：安装后 AI 说找不到技能？
A：确认 zip 已解压到技能目录、SKILL.md 在第一层。

Q2：爆款数据接口返回空？
A：免费接口数据有限，属正常。配红狐 Key 后数据全。

Q3：发布类技能报「未找到配置」？
A：先按上面教程配置公众号凭证再发布。

Q4：微信自动发送没反应？
A：需要电脑微信保持登录打开状态（GUI 自动化原理）。
