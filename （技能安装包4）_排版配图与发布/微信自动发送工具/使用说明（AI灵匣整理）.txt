# WeChat Sender Pro

Windows 微信自动发送工具。支持搜索微信联系人并发送文字、图片、文件。通过 GUI 自动化控制微信窗口，无需微信开放接口。

### 发送文件时的完整流程（人工触发）

用户说「发 xxx 文件给 “张三”」时，**必须先搜索确认，再发送**：

```
1. 调用 find_file.py --name 关键词 --dirs 搜索目录 搜索文件
2. 根据结果数量选择策略：
   ├─ 0 个     → 告知未找到，请提供完整路径或换关键词
   ├─ 1 个     → 告知文件信息，询问「确认发送？」
   ├─ 2~15 个  → 单行列表，让用户选择序号
   └─ >15 个   → 按目录分组摘要，让用户缩小范围
3. 用户确认后，调用 send_file.py 发送
4. 反馈发送结果
```

**搜索参数说明：**
- `--name`：关键词（模糊匹配，不区分大小写）
- `--dirs`：搜索目录，逗号分隔（默认桌面/下载/文档/Workspace）
- `--depth`：递归深度，默认3
- `--ext`：限定扩展名（如 xlsx、pdf）
- `--limit`：最多返回条数，默认50

## 关键要点

1. **必须用 EnumWindows**：pygetwindow.getAllWindows() 找不到最小化窗口
2. **恢复最小化必须在坐标筛选之前**：最小化窗口的 `GetWindowRect` 返回负坐标(-32000)，如果先按坐标筛选会误排除真正的微信主窗口，选到隐藏的辅助窗口（症状：只弹表情包按钮）。正确流程：先对所有候选窗口 `IsIconic` + `ShowWindow(9)` 恢复，等坐标变为正后再筛选面积最大的可见窗口。用 `ShowWindow(hwnd, 9)` (SW_RESTORE)，不能用 `ShowWindow(hwnd, 5)` (SW_SHOW)
3. **关闭子窗口**：通过类名 `Chrome_WidgetWin` 找到并关闭公众号弹窗等子窗口
4. **两次回车**：第一次确认选择联系人，第二次进入聊天窗口
5. **点击输入框**：进入聊天后必须点击输入框区域才能粘贴内容
6. **清空残留搜索词**：点击输入框后，必须 **Ctrl+A → Delete → Ctrl+A** 清空残留内容（搜索联系人后输入框可能残留搜索词如"YHD"，光 Ctrl+A 有时选不全）
7. **不要按 ESC**：ESC 会关闭微信窗口导致焦点丢失
8. **中文编码**：Python 脚本开头加 `sys.stdout.reconfigure(encoding='utf-8')`
9. **图片格式**：微信只接受 BMP/DIB 格式，必须转换
10. **前台切换必须用 AttachThreadInput**：单独调用 `SetForegroundWindow` 或 `SetWindowPos(HWND_TOPMOST)` 均不可靠。Windows 只允许前台进程的线程切换前台窗口，必须用以下组合：
   ```python
   foreground_thread = user32.GetWindowThreadProcessId(user32.GetForegroundWindow(), None)
   wechat_thread = user32.GetWindowThreadProcessId(hwnd, None)
   user32.AttachThreadInput(foreground_thread, wechat_thread, True)  # 附加线程
   user32.keybd_event(0x12, 0, 0, 0)  # 模拟 Alt 键（欺骗 Windows）
   user32.keybd_event(0x12, 0, 2, 0)
   user32.SetForegroundWindow(hwnd)
   user32.AttachThreadInput(foreground_thread, wechat_thread, False)  # 取消附加
   ```

【安装方式】（把 ZIP 拖进对话框，发一句话就装好）

  第 1 步｜上传
      把本文件夹里的 wechat-sender-pro.zip 直接拖进 AI 对话框（和发图片一样），
      不用解压、不用找文件夹、不用装任何软件。

  第 2 步｜复制下面这句话，粘贴发送

      「请解压并安装这个技能包：微信自动发送工具。
       装好后告诉我安装结果，以及之后怎么调用它。」

  第 3 步｜收到「安装完成」就能用了
      直接说「使用微信自动发送工具」，或者干脆直接描述你的需求。

  · 一次装多个：把多个 zip 一起拖进对话框，再发
    「请把上面这些技能包全部解压安装」。
  · 不限定哪个 AI：只要你的 AI 支持上传文件、能读写自己的
    技能目录就能用，不绑定平台或品牌。它要是说不会装，补一句：
    「把技能包解压后放进你的技能目录，SKILL.md 在第一层即可」。
  · 装好后不联网也能用；带脚本的技能需要本机有 Python 3.8+。

· 本技能包由「淘宝店：AI灵匣」整理提供，安装后即可通过自然语言触发。
